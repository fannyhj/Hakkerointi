## Convert hex to base64


Aloitin enismmäisestä cryptopalsin tehtävästä ja olin jo heti hukassa, joten katsoin opettajan vinkkejä tehtäväsivuilta. Näistä ei kuitenkaan ollut melkein
mitään apua, joten lähdin googlettelemaan tehtävän ratkaisua pythonilla. Löysin Shanthanu9 nimisen käyttäjän GitHub tiedoston, jonka ohjeistuksella lähdin
tekemään tehtävää.


Yritin kirjoittaa pyhtonilla virtuaalikoneessani terminaaliin koodia, mutta en saanut millään sitä toimimaan. Murruin ja pyysin tekoälyltä (ChatGPT) apua.


Kirjoitin sitten seuraavanlaisen koodin:


import base64


hex_string = "49276d206b696c6c696e6720796f757220627261696e206c696b65206120706f69736f6e6f7573206d757368726f6f6d"


raw = bytes.fromhex(hex_string)

b64 = base64.b64encode(raw)


print(b64.decode())

## Single-byte XOR cipher


Tämän tehtävän pyhton koodi: 


cipher = bytes.fromhex(

"1b37373331363f78151b7f2b783431333d78397828372d363c78373e783a393b3736"

)

for key in range(256):

    decoded = bytes(c ^ key for c in cipher)
    
    print(key, decoded)
